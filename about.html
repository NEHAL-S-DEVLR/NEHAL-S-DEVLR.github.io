001

It started with design

Posters, logos and social creatives for local businesses — the kind of work where you learn fast because the client sees the result the same week. That became SPREAD Media.

Design
002

Then the clients needed websites

Design files only go so far. I taught myself HTML, CSS and JavaScript so I could hand over a live site instead of a mockup — and stopped depending on anyone else to ship.

Code
003

Then they needed systems

A gym doesn't just need a homepage; it needs members, trainers, attendance and payments. That's where dashboards, databases and role-based access came in.

Software

AIRO exists because the pieces kept repeating. Brand, site, software, marketing — do it once properly, then turn it into something reusable.
